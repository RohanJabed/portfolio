# Rohan Jabed — Portfolio

A custom dark editorial-style portfolio built with Next.js and React.

## Highlights

- Responsive single-page portfolio
- Featured projects and GitHub repository section
- Skills/toolkit section
- Final-year research section
- Contact + social links
- **Resume download** wired to `public/Rohan_Jabed_Resume.pdf`
- No external image assets required

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy

This project is ready for Vercel or any platform that supports Next.js.

## Update project links

The featured projects currently point to the GitHub profile. Replace each `href` in `app/page.tsx` with the exact repository/demo URL when you have them.

## Resume

Put the latest resume at:

`public/Rohan_Jabed_Resume.pdf`
